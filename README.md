# Atividade3_CursoGIT
Este projeto foi desenvolvido como parte integrante do curso "GIT: do básico ao avançado" promovido pela PUCPR. O objetivo principal foi aplicar na prática os comandos de controle de versão e gerenciar o fluxo de trabalho em um repositório Git.
Ferramentas utilizadas:
Git (linha de comando).
GitHub (plataforma de hospedagem).
